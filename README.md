# CSV Quality Report Tool

CSVファイルを自動検査し、結果を見やすいExcelレポートとして出力するPythonツールです。

手作業によるCSV確認の負担を減らし、欠損データや重複データの見落としを防ぐことを目的に作成しました。

## 主な機能

- データ件数と列数の集計
- 欠損セル数の確認
- 重複データの確認
- 各列のデータ型、有効データ数、欠損数、ユニーク数の集計
- 問題が含まれる行の抽出
- 検査結果のExcel出力
- UTF-8およびCP932形式のCSV読込

## 出力されるシート

| シート名 | 内容 |
| --- | --- |
| 検査結果 | 件数、欠損数、重複数、総合判定 |
| 列情報 | 各列のデータ型や欠損数 |
| 欠損行 | 空欄を含む行 |
| 重複行 | 重複している行 |
| 元データ | 読み込んだCSVの全データ |

## 動作環境

- Python 3.14.7
- pandas 3.0.5
- openpyxl 3.1.5

## インストール

このフォルダーで次のコマンドを実行します。

```powershell
python -m pip install -r requirements.txt
```
